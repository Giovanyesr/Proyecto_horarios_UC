# Informe de Cierre del Proyecto

## 1.1 Introducción
El presente informe de cierre tiene como finalidad documentar los resultados obtenidos durante el desarrollo del proyecto **SGOHA (Sistema de Generación Óptima de Horarios Académicos)**, así como las experiencias, aprendizajes y logros alcanzados por el equipo de trabajo a lo largo del ciclo de vida del proyecto.

El desarrollo de SGOHA surgió como respuesta a la necesidad de optimizar la generación de horarios académicos, un proceso que tradicionalmente demanda una considerable inversión de tiempo y esfuerzo por parte del personal administrativo y académico. Mediante la aplicación de metodologías ágiles, herramientas modernas de desarrollo y técnicas de optimización basadas en restricciones, fue posible construir una solución tecnológica orientada a mejorar la eficiencia de este proceso.

El cierre del proyecto representa no solamente la culminación de una etapa académica, sino también la consolidación de conocimientos adquiridos en áreas como gestión de proyectos, ingeniería de software, desarrollo web, bases de datos, arquitectura de software, trabajo colaborativo y resolución de problemas complejos.

## 1.2 Resumen Ejecutivo del Proyecto
El proyecto SGOHA fue concebido con el objetivo de automatizar la generación de horarios académicos mediante el uso de algoritmos de optimización capaces de considerar múltiples restricciones relacionadas con docentes, cursos, aulas y disponibilidad horaria.

La solución desarrollada integra tecnologías modernas como React para el frontend, Node.js y Express para el backend, MongoDB para la gestión de datos y un motor de optimización basado en **Constraint Satisfaction Problem (CSP)**.

Durante el desarrollo se implementó un enfoque adaptativo e iterativo, permitiendo incorporar mejoras continuas, validar funcionalidades y gestionar cambios conforme evolucionaban los requerimientos del proyecto. El resultado final es una plataforma web funcional capaz de contribuir significativamente a la mejora de la gestión académica institucional.

## 1.3 Objetivos Alcanzados

### Objetivo General
Desarrollar un sistema web capaz de generar horarios académicos de manera automática y eficiente, considerando restricciones académicas y administrativas para reducir conflictos y optimizar recursos institucionales.

**Nivel de Cumplimiento:** 100 %

### Objetivos Específicos Alcanzados

**Gestión de Recursos Académicos**
- Se logró implementar módulos para la administración de docentes, cursos, aulas y horarios, permitiendo centralizar la información necesaria para la generación automática de horarios.
- **Estado:** Cumplido.

**Implementación del Algoritmo de Optimización**
- Se desarrolló un motor basado en CSP que permite analizar múltiples restricciones y generar propuestas de horarios válidas.
- **Estado:** Cumplido.

**Desarrollo de una Plataforma Web Moderna**
- Se construyó una aplicación web utilizando tecnologías modernas que garantizan escalabilidad, mantenibilidad y facilidad de uso.
- **Estado:** Cumplido.

**Gestión Segura de la Información**
- Se implementaron mecanismos de autenticación y protección de datos que permiten controlar el acceso al sistema.
- **Estado:** Cumplido.

**Aplicación de Estándares de Calidad**
- Se incorporaron criterios relacionados con ISO/IEC 25010, OWASP Top 10, WCAG 2.1 y Green Software.
- **Estado:** Cumplido.

## 1.5 Principales Logros del Proyecto
Uno de los mayores logros obtenidos fue la capacidad de transformar un problema complejo de planificación académica en una solución tecnológica funcional y escalable. El proyecto permitió demostrar que es posible automatizar procesos tradicionalmente manuales mediante el uso de algoritmos de optimización, reduciendo significativamente la probabilidad de errores y conflictos en la asignación de horarios.

Asimismo, el desarrollo fortaleció las competencias técnicas y profesionales del equipo, permitiendo aplicar conocimientos adquiridos durante la formación universitaria en un contexto cercano a situaciones reales de la industria del software. Otro logro importante fue la implementación de buenas prácticas de desarrollo y gestión de proyectos, lo que contribuyó a mantener la organización y calidad del trabajo realizado.

## 1.6 Dificultades Encontradas
Durante la ejecución del proyecto se presentaron diversos desafíos que requirieron análisis, adaptación y trabajo colaborativo para ser superados.

- **Complejidad del Problema:** La generación automática de horarios involucra numerosas restricciones que pueden entrar en conflicto entre sí.
- **Integración de Componentes:** La comunicación entre frontend, backend, base de datos y motor CSP requirió múltiples pruebas y ajustes.
- **Gestión del Tiempo:** La coordinación de actividades académicas con las responsabilidades del proyecto representó un reto importante.
- **Evolución de Requerimientos:** A medida que avanzaba el proyecto surgieron nuevas necesidades y mejoras.

## 1.7 Lecciones Aprendidas
Entre las principales lecciones aprendidas destacan:
