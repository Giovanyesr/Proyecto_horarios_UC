# Accesibilidad Web según WCAG 2.1

## 1.1 Introducción
La accesibilidad web busca eliminar barreras que dificultan el acceso a la información y funcionalidades de una aplicación. Para ello, las **WCAG 2.1** establecen principios y recomendaciones que permiten diseñar interfaces más inclusivas y fáciles de utilizar. 

En el desarrollo de **SGOHA** se consideraron diversos criterios de accesibilidad para mejorar la experiencia de los usuarios y garantizar el acceso equitativo a las funcionalidades del sistema.

## 1.2 Principios de Accesibilidad Aplicados
Las WCAG se basan en cuatro principios fundamentales:

### Perceptible
La información y los componentes de la interfaz deben presentarse de manera que los usuarios puedan percibirlos.

**Implementación en SGOHA:**
- Uso de textos legibles.
- Etiquetas descriptivas en formularios.
- Títulos y encabezados organizados jerárquicamente.
- Contraste adecuado entre texto y fondo.
- Mensajes de error claramente identificables.

**Resultado:** Cumple.

### Operable
Los componentes de la interfaz deben poder utilizarse mediante diferentes métodos de interacción.

**Implementación en SGOHA:**
- Navegación estructurada mediante menús.
- Botones claramente identificados.
- Formularios accesibles.
- Acciones intuitivas para el usuario.

**Resultado:** Cumple.

### Comprensible
La información y el funcionamiento del sistema deben ser fáciles de entender.

**Implementación en SGOHA:**
- Terminología académica conocida por los usuarios.
- Mensajes claros y descriptivos.
- Diseño consistente entre módulos.
- Retroalimentación inmediata ante errores o acciones exitosas.

**Resultado:** Cumple.

### Robusto
El contenido debe ser compatible con diferentes navegadores y tecnologías de asistencia.

**Implementación en SGOHA:**
- Desarrollo basado en HTML5.
- Uso de React para interfaces modernas.
- Compatibilidad con navegadores actuales.
- Estructura semántica del contenido.

**Resultado:** Cumple.

## 1.4 Beneficios de la Accesibilidad en SGOHA
La incorporación de criterios de accesibilidad proporciona diversos beneficios:
- Facilita el acceso a usuarios con distintas capacidades.
- Mejora la experiencia general de uso.
- Incrementa la usabilidad del sistema.
- Reduce errores durante la interacción.
- Favorece el cumplimiento de estándares internacionales.
- Contribuye a una educación inclusiva y equitativa.

## 1.6 Conclusiones
La evaluación realizada demuestra que **SGOHA** incorpora criterios fundamentales de accesibilidad establecidos por las **WCAG 2.1**, permitiendo que la plataforma sea utilizada de manera eficiente por una amplia variedad de usuarios. La implementación de interfaces claras, navegación intuitiva, validaciones descriptivas y compatibilidad con tecnologías web modernas contribuye a mejorar la inclusión digital y la calidad general del sistema.

Asimismo, se recomienda continuar fortaleciendo las funcionalidades de accesibilidad mediante futuras mejoras, como soporte avanzado para lectores de pantalla, navegación completa mediante teclado y personalización visual para usuarios con necesidades específicas.
